# Trabajo Práctico HTML y CSS - UX/UI

## Descripción

Este trabajo práctico contiene los ejercicios realizados durante la materia UX/UI, utilizando HTML5 y CSS3.

Se trabajaron conceptos como estructura HTML, tablas, formularios, selectores CSS, modelo de caja, Flexbox, CSS Grid, posicionamiento, variables CSS, diseño responsivo, animaciones y validación de formularios.

Los últimos ejercicios integran estos conceptos mediante galerías responsivas, menús sin JavaScript, formularios multi-step y una Landing Page completa.

## Decisiones de diseño

Se buscó mantener un diseño simple y ordenado, utilizando HTML semántico y CSS separado del contenido.

Se priorizó:
- Diseño responsivo para distintos tamaños de pantalla.
- Uso de Flexbox y Grid para la distribución.
- Accesibilidad mediante `label`, `alt` y etiquetas semánticas.
- Organización del CSS mediante clases y comentarios.
- Interactividad utilizando HTML y CSS sin JavaScript.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Animaciones CSS
